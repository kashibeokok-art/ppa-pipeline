La base de datos de contrato busca responder a las preguntas:

¿Que contratos estan por vencer?

¿Que contratos tiene cierto Suministrador?

¿Donde esta ubicado el Cliente?

¿Quien es el Cliente?

¿Cual es el volumen de energia que contrato el Cliente?

Dado esto se consideraran solo las columnas asociadas a:

1. ID Contrato
2. Rut Suministrador
3. Razon social Suministrador
4. Rut cliente
5. Razon social Cliente
6. Tipo de contrato
7. Fecha de termino - Tambien se considerara como fecha de termino la fecha de termino de renovacion
8. Se considerará solo la energia maxima anual tranzada en el contrato
9. Se considerará solo la potencia maxima anual tranzada en el contrato
10. Barra de Retiro [Nombre no ID]
11. Barra de Suministro [Nombre no ID]
12. Se consideraran solo contratos vigentes
13. Region
14. Subsector economico
