El CMg es un valor que varia cada quinceminutos y es util para conocer a que precio se valoriza la energia retirada e inyectada en el sistema.
Conocer el CMg historico ayuda a analizar costos de suministro, tambien a conocer desacoples en el sistema electrico.

Para esta base de datos se almacenaran datos:

1. Barra Asociada.
2. Registro quinceminutal
3. Registro horario
4. Mes y año
5. Bloque Horario
